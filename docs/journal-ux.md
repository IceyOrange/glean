# Journal 卡片交互契约

> 记录 journal.html 卡片（src/components/journal/CardItem.tsx）的点击 / 展开 /
> 选中 / 编辑规则。2026-07-27 用户反馈"三个维度下点击、选中、引文展示、修改的
> 逻辑有点乱"后梳理确立。改动 CardItem 交互前必读。

## 三个状态维度

1. **引文长度**——是否被 line-clamp-3 截断（`quoteClamped`）
2. **有无灵感**
3. **灵感长度**——折叠态预览只显示 1 行

## 契约（现行规则）

1. **引文永远可见。** 任何情况下不得把引文包进 `grid-rows-[0fr]` 折叠容器
   （该模式只用于展开态的灵感编辑区）。折叠态引文 line-clamp-3，展开态全文。

2. **点什么，展开什么。**
   - 引文被截断 → 引文可点（cursor-pointer），点击展开；
   - 引文未截断 → 引文不可点（全文已在眼前，无 cursor）；
   - 灵感预览**始终可点**——点击 = 展开卡片并直接进入灵感编辑。这样"短引文 +
     短灵感"（没有任何东西被截断）的卡片也能编辑灵感；长灵感想读全文时，
     编辑器里就是全文，Esc / 点别处退出。
   - 无灵感的折叠卡片：引文不可点，唯一入口是"写灵感"按钮（展开 + 进入编辑）。

3. **展开态点引文 = 折叠回卡片。**

4. **文本选区优先于点击。** 点击若产生了文本选区（`getSelection()` 非空），
   视为复制意图，不触发展开/折叠。两个方向都受保护。

5. **无变化不保存。** blur / Enter 保存灵感时先比对原值，未改动只退出编辑、
   不调用 `updateCard`——它每次都 bump `updatedAt`，假更新会干扰同步层的
   last-write-wins（见 docs/sync.md）。

6. **选择模式下整卡点击 = 勾选。** 引文、灵感预览等内部元素一律不挂点击
   处理器（让其冒泡到 article），只有带 `stopPropagation` 的显式按钮
   （勾选框、问 AI、删除、来源链接）各自响应。

7. **截断测量用 ResizeObserver**（而非一次性 effect），窗口缩放、字体加载
   后 `quoteClamped` 保持新鲜。

## Esc 层级（src/entrypoints/journal/App.tsx）

 mindset → 设置 → 灵感编辑 → 选择模式 → 展开卡片 → 清空搜索词 → 关闭标签页

## 历史教训（旧逻辑的坑）

- 旧 `clickable = expanded || isClamped || !card.thought` 把三个维度搅在一起：
  - "短引文 + 短灵感"的卡片**永远无法展开 → 灵感永远不可编辑**（编辑入口全在
    展开区）；
  - "短引文 + 长灵感"的卡片被截断的是灵感，却只有引文可点——要点没被截断的
    引文才能展开，反直觉；
  - "短引文 + 无灵感"的卡片因 `!card.thought` 可点，展开后只有一个和折叠态
    一模一样的"写灵感"按钮，纯冗余。
- 展开态选中引文复制时，mouseup 触发 click → 卡片折叠，选区丢失。
- blur 无条件下发 `updateCard` → `updatedAt` 假更新。
